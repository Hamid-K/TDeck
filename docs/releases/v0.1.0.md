# TDeck 0.1.0

Initial release: a dedicated multi-column X dashboard using your existing signed-in browser session, with no API key or server.

- Auto-refreshing search, account, and existing-list columns, including your private lists.
- Independently scrolling feeds, saved layouts, local bookmarks, image viewing, and light/dark appearance.
- Columns and preferences persist locally; configuration can be exported and imported.

## Install

Download `tdeck-0.1.0.zip` from this release, extract it to a permanent folder, enable **Developer mode** in `brave://extensions` or `chrome://extensions`, and select that folder with **Load unpacked**. Open TDeck, sign in to X in the same profile, add columns, and click **Connect X**. The `.sha256` attachment provides the ZIP's SHA-256 checksum.

Keep TDeck's separate source window open and unminimized. Updates use ordinary X pages, not a guaranteed complete realtime stream. Reply, repost, like, compose, and video playback open X. AI Recap is not included.

Validated with 116 passing tests, TypeScript checks, and a production build. Live acceptance passed in Brave on macOS; Chrome shares the Chromium build target but has not been separately live-tested.
